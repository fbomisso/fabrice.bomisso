## Présentation

Ce projet porte sur la préparation de données destinées à faciliter leur exploitation et leur analyse dans Power BI.

La première phase a consisté à nettoyer, structurer et contrôler plusieurs sources de données avant leur intégration dans un environnement d'analyse.

## Données traitées

- Organisations à but non lucratif
- Opportunités de financement
- Données de qualité des organisations
- Données préparées pour l'analyse

## Technologies

Python · Pandas · NumPy · Matplotlib · Seaborn · Power BI
